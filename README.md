# MindEase 🧠

MindEase is an Android mental wellness application designed to help users build healthier daily habits through reminders, authentication, and interactive mini-games.

## ✨ Features

- User authentication using Firebase Authentication
- Cloud data storage using Firebase Cloud Firestore
- Reminders to support daily routines
- Interactive mini-games:
  - Bubble Pop
  - Star Catcher

## 🛠️ Technologies Used

- Java
- XML
- Firebase Authentication
- Firebase Cloud Firestore
- Android Studio
- Figma
- Jira

## 📱 Platform

Android

## 👥 Development

MindEase was developed as a team project.

## 🎯 Project Goal

The goal of MindEase is to provide a simple, interactive mobile experience that supports users' mental wellness and everyday routines.

## 📌 Project Status

Developed as an academic team project.
